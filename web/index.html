측정 파일 준비
  1. 같은 모델 리비전·토크나이저·정밀도·데이터·길이·부하 패턴을 사용합니다. 데이터셋, 시드, 캐시 정책, 요청률, 워밍업 조건이 달라지면 워크로드 이름을 구분하세요.
  2. GPU 또는 TPU에서 서버 설정을 바꿔 재기동하고 워밍업한 뒤 같은 시험을 반복합니다. environment에 장비·수량·백엔드 버전·TP/DP 등 고정한 서버 조건을 기입합니다.
  3. 아래 CSV 양식에 실행 1회당 한 행을 입력하거나 아래 형식의 vLLM JSON을 준비합니다. 함께 분석할 파일은 한 번에 선택하세요. 새로 열면 현재 데이터 전체를 교체합니다.


CSV 열과 단위
열 이름입력 내용


run_id, scenario, model, dtype고유 실행 ID, 워크로드 이름, 모델과 리비전, 정밀도. 같은 실행을 중복으로 합산하지 않도록 ID는 파일 전체에서 유일해야 합니다.


environment예: H100×8 · vLLM 버전 · TP8/DP1. H200, H100, Ironwood, 서로 다른 칩 수와 소프트웨어 구성을 개별 이름으로 기록합니다.


input_tokens, output_tokens, concurrency시나리오의 요청당 입력·출력 길이와 클라이언트 동시 요청 상한. 가변 길이는 대표 길이와 분포 식별자를 함께 기록합니다. 실제 스케줄러 배치 크기는 별도입니다.


max_num_seqs, max_num_batched_tokens, max_model_len서버에서 확인한 스텝당 시퀀스 상한, 스텝당 전체 토큰 예산, 요청당 문맥 상한입니다.


status, quality실행 결과 ok / error / oom. 요청 실패가 한 건이라도 있으면 error입니다. 별도의 출력 정합성 평가 결과는 pass / fail / unknown입니다. 미입력은 unknown으로 처리합니다.


p95_ttft_ms, p95_itl_ms, output_throughput각각 첫 토큰 지연 p95(ms), 연속 출력 토큰 간 지연 p95(ms), 초당 출력 토큰 수입니다. 정상 행은 양수만 허용합니다. 토큰 1개만 생성해 ITL이 정의되지 않는 시험은 지원 범위 밖입니다. 실패 행에는 성능 칸을 비워도 됩니다.


request_throughput선택 항목. 초당 완료 요청 수입니다. 누락된 반복이 있으면 요청/초 기준 추천에서 해당 설정을 제외합니다.


data_kinddemo / measured. 생략 시 measured입니다. 예시 CSV를 수정해 실험값을 넣었다면 measured로 바꾸세요. 두 종류의 혼합 입력은 차단합니다.




vLLM 결과 JSON 사용
실행 중인 서버를 대상으로 아래 예시의 모델명·메타데이터·동시성·요청 수를 시험 조건에 맞춥니다. 서버 상한은 별도로 기동한 엔진의 실제 값과 일치해야 합니다. run_id는 매 실행 바꿉니다.


단일 객체, 객체 배열, 여러 JSON 파일을 지원합니다. output_throughput과 p95 TTFT·ITL을 읽고, failed 또는 completed / num_prompts로 실패를 판정합니다. 누락된 p95를 p99로 대체하지 않습니다. JSON 구조가 다른 버전은 위 CSV 양식을 사용하세요.

추천과 재시험 기준
같은 워크로드·환경·동시성에서 실행에 성공하고 SLO를 충족한 설정 중 선택한 처리량이 가장 큰 값을 고릅니다. 동률이면 ITL, TTFT, 시퀀스 상한, 토큰 예산, 문맥 상한이 작은 순입니다. 정합성 실패는 항상 제외하며, 체크를 해제하면 미검증 결과를 포함합니다. TTFT와 ITL의 p95를 각각 검사하므로 두 기준을 동시에 만족한 요청 비율은 별도 요청 로그로 계산해야 합니다.
파레토 경계는 추천 조건을 충족한 설정 중 그래프의 두 지표를 동시에 개선할 수 없는 점들을 잇습니다. 선 사이의 설정은 미측정 구간입니다. 설정을 바꿔도 처리량 증가가 작으면 서버의 실행·대기 요청 수, KV 캐시 사용률, 재계산과 컴파일 로그를 같은 시간대에서 확인하세요.
11월 18일 회의에서 언급한 시퀀스 상한 4,096과 토큰 예산 8,192~16,384는 재시험 후보입니다. 이 화면의 예시 수치는 가상의 반복 측정값이며 장비 간 성능 비교 자료로 사용할 수 없습니다.
